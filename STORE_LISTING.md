## Detailed description

SnapSave makes webpage capture feel effortless. Capture what you see, drag over exactly what you need, or save a complete scrolling webpage. Preview the result, copy it, or download it as PNG, JPG, or a clean paginated PDF.

Everything happens locally in Chrome. SnapSave has no accounts, analytics, ads, cloud uploads, or remote code.

## Key features

- Visible viewport screenshots
- Precise drag-to-select capture with dimensions and Escape cancellation
- Full-page scroll-and-stitch capture
- PNG, JPG, and paginated PDF export
- Clipboard copy
- Clean automatic filenames
- Configurable quality, format, downloads, and Chrome-managed shortcuts

## Privacy statement

SnapSave does not collect or transmit browsing history, page content, screenshots, personal information, or usage analytics. All capture and conversion work happens locally. No data is sold or shared.

## Permission explanations

`activeTab` temporarily accesses only the page where the user starts a capture. `scripting` provides the selection and full-page scroll helpers. `storage` saves preferences. `downloads` saves requested files. `clipboardWrite` supports copy. No broad host permission is requested.
