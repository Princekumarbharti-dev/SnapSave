# SnapSave Privacy Policy

**Effective date: August 22, 2026**

SnapSave does not collect, store, transmit, sell, or share personal information, browsing history, webpage content, screenshots, or usage analytics. It has no accounts, advertising, analytics SDKs, backend, or cloud storage.

Screenshots and conversions are processed locally inside Google Chrome. The latest capture may remain briefly in volatile extension memory so the preview can display it; it disappears when replaced or when Chrome stops the extension service worker. User preferences are stored with Chrome's extension storage and may be synchronized by Chrome when browser sync is enabled.

SnapSave requests only the permissions described in the project README and Chrome Web Store listing. It does not request access to every website. Access to a webpage is temporary and begins only after a user invokes a capture action.

Questions about this policy should be directed to the support contact listed on SnapSave's eventual Chrome Web Store page.
